# omp-prompt-polish

在 Tern 的 omp 输入框里一键润色草稿，结合最近聊天理解指代，并可恢复原文。

## 安装

需要 Tern 和 omp 18.13.1 或更新的 18.x。使用 omp 已配置的模型和认证，无需另填 API key。

在项目目录执行：

```sh
omp plugin link .
```

安装或更新代码后，退出并重新启动 omp，或打开一个新的 omp 窗格。运行中的进程不会自动加载变更。

仅试用一次：

```sh
omp --extension ./src/index.ts
```

## 使用

点击发送按钮左边的星星。当前仅提供 Tern 原生按钮，不注册快捷键。

同一个按钮根据当前状态执行操作：

| 当前状态 | 点击按钮 |
| --- | --- |
| 已输入草稿，显示星星 | 开始润色 |
| 正在润色，仅显示转圈 | 取消本次请求 |
| 润色完成，显示还原图标 | 恢复原文，丢弃本次润色结果 |
| 润色期间修改了草稿，结果已就绪 | 应用润色结果，并将最新草稿保留为可恢复的原文 |

恢复原文后按钮变回星星，再次使用会重新润色。润色不会自动发送消息；清空输入、发送或切换会话后，本次恢复状态结束。

## 润色内容与上下文

默认整理表达、语法和结构，保留草稿的语言、语气及意图，不擅自增加需求。

- 参考当前会话分支最近最多 **6 条**用户消息和已完成的助手回复，通常约 3 轮。
- 历史正文总量最多约 12,000 字符，每条最多约 4,000 字符；超长时优先保留最新消息和消息结尾。
- 用于理解“上面那个”“按刚才说的做”等指代；用户后来的纠正优先。不确定的内容不猜测。
- 不读取其他分支、清空边界之前的消息、工具输出、思考过程或图片数据。

代码、附件标记、常用 URL 和路径会先保护，模型破坏标记时不会写回结果。当前草稿中的附件及大段粘贴只发送受保护标记，不读取展开内容；历史只提取已有消息正文。

润色请求使用当前模型的账户额度，不把润色过程追加到主聊天。原文快照仅保存在当前进程内，用于本次恢复。

斜杠命令、Shell/Python 输入模式、子代理视图和正在录音或转写的草稿不启用润色。

## 兼容性

已在 Windows、Tern 0.9.5、omp 18.13.2 上验证按钮点击。macOS 使用相同的 Tern 原生点击接口，但尚未实机验证。

## 开发

```sh
npm install
npm run check
npm test
```

无需构建，omp 直接加载 TypeScript。
